Cheat Sheet: Warna Semantik

Setiap warna punya peran. Pakai token, jangan hardcode.
Accent / Primary --accent #38bdf8
Success --accent-2 #34d399
Warning --warn #fbbf24
Danger / Error --danger #fb7185
Purple / Info --purple #a78bfa
Muted / Disabled --muted #7d8fa8
Surface --surface #0f1520
Background --bg #080b12
💡 Prinsip Warna

Satu warna = satu makna. Jangan pakai --danger untuk dekorasi. Jangan pakai --accent untuk status sukses. Konsistensi makna > keindahan visual.

Code Block

Dengan tombol salin & syntax highlight
javascript 
// Theme switcher minimal
const root = document.documentElement;

function setTheme(theme) {
  root.setAttribute('data-theme', theme);
  localStorage.setItem('theme', theme);
}

// Init: localStorage → preferensi OS → dark
const saved = localStorage.getItem('theme')
  || (matchMedia('(prefers-color-scheme: light)').matches
      ? 'light' : 'dark');
setTheme(saved);

Design system minimal dengan token-driven CSS variables, dual theme, dan komponen yang saling terintegrasi. Fokus pada data-dense UI tanpa kehilangan estetika.

16

Tips Konsistensi

Aturan emas agar design system tetap koheren
1
Jangan hardcode warna. Selalu pakai token — var(--accent), bukan #38bdf8. Kalau butuh warna baru, tambahkan sebagai token baru.
2
Pakai color-mix() untuk opacity. Lebih fleksibel daripada rgba() karena otomatis menyesuaikan tema.
border-color: color-mix(in srgb, var(--accent) 35%, var(--border));
3
Satu easing curve. Pakai --ease-soft (cubic-bezier(.4,0,.2,1)) untuk micro-interaction, --ease-out (cubic-bezier(.16,1,.3,1)) untuk entrance.
4
Glow radial di body::before adalah signature look. Jangan dihapus — kalau diganti, ganti juga --bg-glow-1 dan --bg-glow-2.
5
Border dulu, shadow kemudian. Elevate dengan border warna accent, bukan shadow tebal. Shadow hanya untuk elemen melayang (modal, toast, tooltip).
6
Font mono untuk angka. IP, statistik, kode, ID — semua var(--font-mono). Ini yang membuat UI terasa "teknis" dan rapi.
7
Hormati prefers-reduced-motion. Sudah dihandle di base.css — jangan di-override.
◆ Intinya

Design system yang baik = konsistensi > kreativitas per-komponen. Kalau ada kebutuhan baru, tambahkan sebagai token/varian, jangan bikin one-off style.
