01

Cheat Sheet: Semantic Colors

Every color has a role. Use tokens, don't hardcode.
Accent / Primary --accent #38bdf8
Success --accent-2 #34d399
Warning --warn #fbbf24
Danger / Error --danger #fb7185
Purple / Info --purple #a78bfa
Muted / Disabled --muted #7d8fa8
Surface --surface #0f1520
Background --bg #080b12
💡 Color Principle

One color = one meaning. Don't use --danger for decoration. Don't use --accent for success status. Consistency of meaning > visual beauty.

Code Block

With copy button & syntax highlighting
javascript 
// Minimal theme switcher
const root = document.documentElement;

function setTheme(theme) {
  root.setAttribute('data-theme', theme);
  localStorage.setItem('theme', theme);
}

// Init: localStorage → OS preference → dark
const saved = localStorage.getItem('theme')
  || (matchMedia('(prefers-color-scheme: light)').matches
      ? 'light' : 'dark');
setTheme(saved);

16

Consistency Tips

Golden rules to keep the design system coherent
1
Never hardcode colors. Always use tokens — var(--accent), not #38bdf8. Need a new color? Add it as a new token.
2
Use color-mix() for opacity. More flexible than rgba() because it adapts to the theme automatically.
border-color: color-mix(in srgb, var(--accent) 35%, var(--border));
3
One easing curve. Use --ease-soft (cubic-bezier(.4,0,.2,1)) for micro-interactions, --ease-out (cubic-bezier(.16,1,.3,1)) for entrances.
4
The radial glow on body::before is the signature look. Don't remove it — if you replace it, also replace --bg-glow-1 and --bg-glow-2.
5
Border first, shadow later. Elevate with an accent-colored border, not a heavy shadow. Shadows are only for floating elements (modal, toast, tooltip).
6
Mono font for numbers. IPs, statistics, code, IDs — all var(--font-mono). This is what makes the UI feel "technical" and tidy.
7
Respect prefers-reduced-motion. Already handled in base.css — don't override it.
◆ The Bottom Line

A good design system = consistency > per-component creativity. If a new need arises, add it as a token/variant — don't create one-off styles.
